# 🛠️ ORIGINS SECUNDUS *(в разработке)*

**ORIGINS SECUNDUS** - это мод, вдохновлённый [Origins](https://www.curseforge.com/minecraft/mc-mods/origins), с акцентом на **глубокую кастомизацию персонажей** и **уникальные расы**.  
Главная фишка - **продвинутый редактор персонажа** в духе TES, с возможностью настройки внешности (цвет кожи, тип глаз, лицо, рост и т.д.) под каждую расу. 
У каждой расы есть свои уникальные настройки. Например у эльфов - можно выбрать тип ушей, у орков - клыки и т.д. Также у всех рас есть "под-расы", 
каждая из которых имеет уникальные настройки и особые способности.

## ✨ Основные особенности

- 🧬 **Уникальные и знакомые расы** - с разными способностями, внешним видом и деталями модели, многие уже хорошо знакомы.
- 🧑‍🎨 **Редактор внешности** - настройки тела, причесок, глаз, ушей, рогов, клыков, шрамов, растительности и чего угодно.
- 🧩 **Кросссовместимость** - мод разрабытывается с заделм на широкую совместимость с версиями и другими модами.
- 🕺 **Планируется поддержка Epic Fight** - кастомные анимации для некоторых рас, например уникальный бег для зверолюдей.
- ✏️ **Кастомизация** - возможность легко добавлять свои расы, способности и модельки через data/resourse packs как в оригинальном [Origins](https://www.curseforge.com/minecraft/mc-mods/origins).

### 🔒 Скрытые расы (доступны по ходу игры)

*Вампир, Одержимый, Злой дух, Оборотень*

Их можно получить выполнив определенные условия. Например получить укус от вампира и не умереть (=вампир), 
отдать демону душу (=одержимый), получить проклятие после смерти (=злой дух). 

При этом у некоторых рас есть резист к этим условиям. Например демон не может получить ни один из этих статусов,
голем не может стать вампиром или оборотнем. 

Остальные расы при успешной эволюции не меняются а получают новый статус. Например: одержимый гигант, гоблин-вампир,
одержимый дух некроманта, человек оборотень. Способности и пассивные бафы/дебафы получают переработку, в зависимости
от изначальной расы.
